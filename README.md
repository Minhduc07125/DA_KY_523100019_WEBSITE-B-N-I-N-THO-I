## 2. Mục tiêu đề tài
- Xây dựng hệ thống website thương mại điện tử chuyên cung cấp và kinh doanh các dòng điện thoại di động chính hãng và phụ kiện công nghệ.
- Hỗ trợ khách hàng tra cứu thông tin sản phẩm, xem chi tiết thông số kỹ thuật (chip, RAM, pin, camera), tìm kiếm nhanh chóng và quản lý giỏ hàng/đơn hàng thuận tiện.
- Cung cấp trang quản trị (Admin) giúp người quản lý dễ dàng thêm, sửa, xóa sản phẩm và theo dõi số lượng tồn kho theo thời gian thực.

## 3. Chức năng cốt lõi của hệ thống
- **Phía Khách hàng (Client):**
  - Xem danh sách sản phẩm nổi bật, phân loại theo hãng (Apple, Samsung, Xiaomi,...).
  - Tìm kiếm sản phẩm thông minh theo tên hoặc thương hiệu.
  - Xem trang chi tiết sản phẩm, giá bán và thông số kỹ thuật cấu hình chi tiết.
- **Phía Quản trị viên (Admin):**
  - Quản lý danh mục sản phẩm (Thêm mới sản phẩm, cập nhật giá, cấu hình).
  - Quản lý kho hàng và theo dõi số lượng tồn kho của từng biến thể điện thoại.

## 4. Công nghệ sử dụng
- **Front-end:** EJS (Embedded JavaScript Templates), HTML5, CSS3, Responsive Design.
- **Back-end:** Node.js, Express.js Framework.
- **Database (Cơ sở dữ liệu):** SQLite (Hệ quản trị cơ sở dữ liệu quan hệ gọn nhẹ, dễ triển khai).
- **Công cụ hỗ trợ:** Visual Studio Code, Git & GitHub, Postman.
